# My Games

Редактируйте `data.js`, загружайте изображения в `images/`. Поддерживаются любые пропорции изображений. Поля nickname, description, platform и buttons необязательны. Для кнопок задайте label и url. Публикация GitHub Pages: ветка main, папка / (root). Начальные три игры приведены без изображений и ссылок; замените их своими данными.
